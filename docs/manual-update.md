# 面板内手动更新

六家银行的操作面板和公开／登录页入口，在顶部当前版本号旁提供 **Update**。

- 点击后在新标签页打开统一 `.user.js` 安装包，由 Tampermonkey 处理安装／更新。完成后手动刷新银行页面加载新版本。
- 安装地址由构建过程从统一发布身份和仓库配置生成，与 `@downloadURL` 一致，不维护另一份硬编码地址。
- 页面加载、恢复缓存和闲置时不会检查新版本或请求安装文件。入口不显示未经核验的“已是最新版本”或“更新成功”。
- 原银行页面不导航、不自动刷新；不会改变已选卡片、优惠缓存或启动任何银行请求。折叠面板后入口仍可见。
- 新标签页不保留 opener，也不向下载地址发送银行页面的 Referer。

Chromium 合成回归覆盖六家操作面板及六个登录／公开入口：点击实际打开正确地址、无自动检查、当前版本、折叠、重复注入、存储不变、320px 窄屏布局。下载页面由测试拦截，未在真实 Tampermonkey 中执行升级；扩展安装确认和升级后的真实页面行为待现场验证。

1.5.2 发布验证：`npm run build`、`npm run check`、`npm test`（384 项）、`npm run test:browser`（16 组浏览器回归及 11 个 Gherkin 场景／106 个步骤）均 PASS。
